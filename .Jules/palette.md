## 2025-05-18 - Chat Stream Speaker and Processing Semantics for Screen Readers
**Learning:** In Jetpack Compose chat streams, speech bubbles that differentiate the sender (user vs. AI copilot) solely via visual alignment (start vs. end) and background tint (`primary` vs. `surfaceVariant`) are indistinguishable to screen-reader users (TalkBack). Furthermore, an unlabelled `CircularProgressIndicator` used as a typing/processing indicator leaves screen-reader users unaware that the agent is actively computing a response. Providing `Modifier.semantics(mergeDescendants = true)` with explicit speaker attribution (`"You said: ..."` vs `"Agent said: ..."`) and labelling progress indicators (`"Agent is thinking"`) restores parity for non-visual navigation.
**Action:** Always wrap conversational bubbles and dynamic loading indicators with merged semantics containing clear speaker context and descriptive state announcements.
